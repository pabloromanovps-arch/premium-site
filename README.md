# premium-site

Лендинг мастерской механических часов «Ход». Чистый HTML/CSS/JS, без сборки.

- `index.html` — разметка и тексты
- `styles.css` — стили (цвета и шрифты в `:root`)
- `script.js` — живой циферблат (московское время) и проверка формы заявки

Запуск локально: `python3 -m http.server` и открыть http://localhost:8000.
Для публикации подходит GitHub Pages (Settings → Pages → ветка, корень).

Форма заявки пока не отправляет данные — место для подключения отмечено `TODO` в `script.js`.
