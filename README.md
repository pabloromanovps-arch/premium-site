# Стебель — цветочный магазин: сайт, бот в мессенджерах и CRM

Тестовый стенд для обкатки всей цепочки продаж: сайт → чат-бот (сайт, Telegram, ВКонтакте, MAX, Алиса) →
CRM → SMS клиенту и оплата → Telegram менеджеру и внешняя CRM. Чистый HTML/CSS/JS, сборка не нужна.

## Страницы стенда

| Страница | Что там |
| --- | --- |
| `index.html` | Магазин: каталог, корзина, оформление, чат с ботом |
| `channels.html` | Бот в Telegram, ВКонтакте, MAX и Алисе — каждый через настоящий адаптер платформы |
| `crm.html` | CRM: воронка по этапам, карточка с кнопкой следующего шага, оплата, история |
| `lab.html` | Пульт тестирования: время, сбои сервисов, автопрогон сценариев, журнал SMS/Telegram/Метрики |
| `pay.html` | Симуляция платёжной страницы (ссылка приходит клиенту в SMS) |

## Как запустить

**Без установки.** Скачайте репозиторий (Code → Download ZIP), распакуйте, откройте `index.html`.

**Через локальный сервер** (Node.js 18+): `npm start`, затем http://localhost:4173.

**Тесты:** `npm install`, затем `npm test`. Подробно — в [TESTING.md](TESTING.md).

## Код

| Файл | Назначение |
| --- | --- |
| `js/bot.js` | Бот: понимает свободный текст, подбирает букеты, оформляет заказ, статус, обратный звонок |
| `js/channels.js` | Адаптеры Telegram, VK, MAX, Алисы: разбор входящих событий и вызовы API с учётом ограничений |
| `js/store.js` | CRM: заявки, этапы, оплата, комментарии, история |
| `js/sim.js` | Симуляция внешнего мира: время, Telegram менеджеру, внешняя CRM, SMS |
| `js/scenarios.js` | Сценарии автопрогона — одни и те же на пульте и в тестах |
| `js/messages.js` | Тексты SMS клиенту и уведомлений менеджеру |
| `js/metrika.js` | Цели Яндекс.Метрики |
| `server/worker.mjs` | Сервер для настоящих каналов (Cloudflare Workers) |

## Режимы

- **Стенд (по умолчанию).** Всё работает в браузере: заказы в localStorage, «внешние» сообщения — в журнале пульта.
- **Боевой.** Подключение Telegram, ВКонтакте, MAX, Алисы, Метрики и внешней CRM описано в [CHANNELS.md](CHANNELS.md).
