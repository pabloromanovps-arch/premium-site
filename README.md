# ИИ-агент продаж: тестовый стенд на примере «Стебля»

Агент отвечает покупателям в Авито, Telegram, MAX, ВКонтакте, на сайте и в Алисе, ведёт заказы в CRM
и не даёт им остыть: напоминает менеджеру, подтверждает сам, дожимает оплату и брошенные разговоры.
Настраивается под любой бизнес по перепискам сотрудников. «Стебель» — цветочная мастерская для примера.
Чистый HTML/CSS/JS, сборка не нужна.

Открытая ссылка: https://pabloromanovps-arch.github.io/premium-site/

## Как запустить

**Без установки.** Скачайте репозиторий (Code → Download ZIP), распакуйте, откройте `index.html`.

## Как дать потестировать партнёру

**Вместе, в общем режиме (на claude.ai).** Откройте опубликованный стенд → «Поделиться» → пригласите партнёра по email
с ролью «Редактор». Тогда заказы, заявки и журнал общие: партнёр оформляет заказ — он появляется у вас в CRM.
Зелёная точка вверху стенда означает, что общий режим включён. Если открыть стенд по публичной ссылке,
общие заявки будут видны, но свои заказы гостя останутся только у него — стенд честно об этом предупреждает.

**Каждый сам по себе (GitHub Pages).** Settings → Pages → ветка с кодом, папка `/ (root)`. Ссылка открывается у
кого угодно без регистрации, но данные у каждого свои.

**Через локальный сервер** (Node.js 18+): `npm start`, затем http://localhost:4173.

**Тесты:** `npm install`, затем `npm test`. Подробно — в [TESTING.md](TESTING.md).

## Режимы

- **Стенд (по умолчанию).** Всё работает в браузере: заказы в localStorage, «внешние» сообщения — в журнале пульта.
- **Боевой.** Подключение Telegram, ВКонтакте, MAX, Алисы, Метрики и внешней CRM описано в [CHANNELS.md](CHANNELS.md).
