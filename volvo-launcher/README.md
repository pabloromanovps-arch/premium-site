# SPA Launcher

Лаунчер в стиле Volvo Sensus (XC60/XC90 2018–2019, платформа SPA) для Android-магнитолы
1280×480 (Volvo XC60 2010, звук по AUX, без CAN-шины).

## Установка

1. На магнитоле откройте в браузере страницу релиза
   `https://github.com/pabloromanovps-arch/premium-site/releases/tag/launcher-latest`
   и скачайте `SpaLauncher.apk`. Можно скачать на телефон и перенести на флешке.
2. Откройте файл и установите. Если Android попросит, разрешите установку из этого источника.
3. Нажмите «Домой» и выберите **SPA Launcher → Всегда**.
4. На экране «Функции» нажмите «Трек на экране» и включите доступ к уведомлениям для «SPA Launcher».
   После этого на экране будет текущий трек, и его можно переключать.

Погода, город и правильная дата берутся из интернета, GPS не нужен.

Новые версии ставятся поверх старых, настройки сохраняются.

## Экраны

Экраны переключаются свайпом или кнопками внизу:

| ← Приложения | Главный | Функции → |
|---|---|---|
| Избранное и все приложения | Музыка · Навигатор · CarPlay · YouTube · камеры · погода | Камеры, звук, Bluetooth, яркость, тема |

- **Долгое нажатие на ярлык** (Навигатор, Музыка, CarPlay, камеры и т.д.) открывает выбор,
  какое приложение он запускает.
- **Тема** Elegance / Eco / Performance повторяет цвета цифровой приборки Volvo.
- **Звук при включении.** На этой магнитоле звук в AUX появляется после запуска Bluetooth Music.
  Лаунчер после включения сам открывает его на пару секунд и возвращается на главный экран.
  Это можно выключить на экране «Функции».

## Сборка

GitHub Actions собирает APK на каждый пуш в `volvo-launcher/` и выкладывает его в релиз
`launcher-latest`. Локально: `./gradlew assembleRelease` (нужен Android SDK 34, JDK 17).
