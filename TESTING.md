# Тестирование

```bash
npm install          # один раз
npm test             # всё подряд
npm run test:unit    # модульные, интеграционные, контрактные и сценарии — без браузера
npm run test:e2e     # сквозные в браузере, компьютер и телефон
```

Если Playwright попросит браузер: `npx playwright install chromium`.

## Уровни

| Уровень | Где | Что проверяет |
| --- | --- | --- |
| Модульные | `tests/unit/validate`, `cart`, `store`, `bot`, `sim` | Телефоны, даты и интервалы по Москве, доставка, этапы CRM и запреты, оплата, разбор свободного текста ботом |
| Контрактные | `tests/unit/channels.test.js` | Входящие события в формате Telegram, VK, MAX, Алисы; обход всех состояний бота и проверка каждого ответа на ограничения всех четырёх платформ |
| Интеграционные | `tests/unit/integration.test.mjs` | Сайт → сервер → Telegram/CRM; вебхуки мессенджеров на сервере: секреты, подтверждение VK, ответы Алисе; сеть подменяется |
| Сценарии | `tests/unit/scenarios.test.js` и кнопка на пульте | 7 сквозных историй: заказ в боте, самовывоз, оплата с отказом банка, сбой Telegram, вечер, защита от ошибок, нагрузка 50 заявок |
| Сквозные (E2E) | `tests/e2e/*.spec.js` | Настоящий браузер: магазин, чат, воронка CRM, оплата, все мессенджеры, пульт, Метрика, мобильная вёрстка |
| Ручные | чек-лист ниже | Тексты, удобство, внешний вид, настоящие платформы |

## Чек-лист ручной проверки

Откройте рядом магазин, мессенджеры, CRM и пульт.

**Бот (в любом канале)**
- [ ] Одной фразой: «пионы маме на завтра вечером до 5000» — бот не переспрашивает дату и время.
- [ ] «розы к 18, заберу сам», «что-нибудь недорогое», «в субботу утром», «шикарный букет».
- [ ] Цветы, которых нет в готовых букетах («орхидеи») — бот честно говорит и предлагает похожие.
- [ ] Посреди заказа спросить «сколько доставка» — бот отвечает и продолжает с того же места.
- [ ] «Изменить» перед оформлением — меняется только выбранное.
- [ ] «где заказ СТ-…», «позовите человека», «спасибо», «меню».

**CRM**
- [ ] Новый заказ появляется в колонке «Новые» сам, без перезагрузки.
- [ ] Главная кнопка ведёт заказ по этапам; у самовывоза — «Букет готов к выдаче».
- [ ] После подтверждения в журнале пульта — SMS со ссылкой на оплату; оплатить, отказ банка, ещё раз.
- [ ] Отмена спрашивает подтверждение.
- [ ] Поиск, фильтр по каналу, вид «Список», CSV в Excel.

**Пульт**
- [ ] «Запустить все сценарии» — все зелёные.
- [ ] «Вечер, 20:30» — в магазине и в боте сегодня уже не заказать.
- [ ] Включить «Telegram недоступен», оформить заказ — в истории заявки ошибка, заказ на месте.
- [ ] Журнал: SMS, Telegram менеджеру, цели Метрики.

**Устройства:** телефон, планшет, компьютер; Chrome, Safari, Firefox.

**Настоящие платформы** (после подключения по CHANNELS.md):
- [ ] Telegram, ВКонтакте, MAX: заказ кнопками и текстом; кнопки выглядят как в симуляторе.
- [ ] Алиса: проверить во вкладке «Тестирование» Яндекс Диалогов, особенно произношение.
- [ ] Заказ из мессенджера приходит менеджеру в Telegram и во внешнюю CRM.
- [ ] Цели появляются в Метрике (в отчёте «Конверсии», с задержкой).
