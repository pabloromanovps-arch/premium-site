# Тестирование

## Быстрый запуск

```bash
npm install          # один раз, ставит Playwright
npm test             # все уровни подряд
npm run test:unit    # только модульные и интеграционные (без браузера, ~1 с)
npm run test:e2e     # только сквозные в браузере (компьютер + телефон)
```

Если Playwright попросит браузер: `npx playwright install chromium`.

## Уровни

| Уровень | Файлы | Что проверяет |
| --- | --- | --- |
| 1. Модульные | `tests/unit/validate.test.js`, `cart.test.js`, `store.test.js`, `bot.test.js` | Телефоны, даты и интервалы по Москве, порог бесплатной доставки, статусы CRM и запрещённые переходы, каждая ветка чат-бота |
| 2. Интеграционные | `tests/unit/integration.test.mjs` | Сайт → вебхук → сервер → Telegram и CRM. Сеть подменяется: проверяем, что уходит, и что будет при отказе Telegram/CRM |
| 3. Сквозные (E2E) | `tests/e2e/shop.spec.js` | Настоящий браузер, по-пользовательски: заказ с сайта и из чата доходит до CRM, менеджер ведёт его до «Выполнен», CSV, фильтры, мобильная вёрстка |
| 4. Ручные | чек-лист ниже | То, что автотест не оценит: тексты, удобство, внешний вид, реальные Telegram и CRM |

## Чек-лист ручной проверки

Откройте магазин и CRM в двух вкладках рядом.

**Магазин**
- [ ] Добавить 2–3 букета, менять количество, удалить позицию.
- [ ] Набрать корзину до 5 000 ₽ — доставка становится бесплатной.
- [ ] Переключить на самовывоз — поле адреса пропадает, доставка 0 ₽.
- [ ] Отправить пустую форму — у каждого поля понятная ошибка.
- [ ] Выбрать сегодняшнюю дату — ранние интервалы недоступны (нужно минимум 2 часа).
- [ ] Оформить заказ — номер СТ-…, заказ сразу появился во вкладке CRM.

**Чат-бот**
- [ ] Заказ кнопками: бюджет → букет → дата → интервал → доставка → имя → телефон → «Оформить».
- [ ] Написать текстом: «сколько доставка», «где мой заказ», «перезвоните», «абракадабра».
- [ ] Ввести неправильный телефон и дату «31.02» — бот переспрашивает.
- [ ] Узнать статус только что созданного заказа; поменять статус в CRM и спросить снова.
- [ ] Написать «меню» посреди сценария — бот возвращается в начало.

**CRM**
- [ ] Провести заказ с доставкой: Подтверждён → Собирается → В доставке → Выполнен.
- [ ] Провести самовывоз: вместо «В доставке» должен быть «Готов к выдаче».
- [ ] Отменить заказ — статус больше не меняется.
- [ ] Комментарии и история изменений.
- [ ] Поиск по имени, номеру и части телефона; фильтры.
- [ ] Скачать CSV и открыть в Excel — кириллица читается.

**Устройства:** телефон (≈390 px), планшет, компьютер; Chrome, Safari, Firefox.

**Настоящие интеграции** (когда подключите сервер):
- [ ] Заказ с сайта пришёл в Telegram с правильной суммой и адресом.
- [ ] Заявка появилась во внешней CRM.
- [ ] Выключите сервер — заказ всё равно сохраняется, в истории видна ошибка отправки.
