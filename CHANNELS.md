# Подключение настоящих каналов

Всё, что описано ниже, уже работает в симуляции (страница «Мессенджеры» и пульт тестирования).
Чтобы подключить настоящие каналы, нужны аккаунты на платформах и сервер `server/worker.mjs` (Cloudflare Workers, бесплатного тарифа хватает).

## 1. Сервер

```bash
npx wrangler login
npx wrangler kv namespace create SESSIONS     # хранилище диалогов; id впишите в wrangler.toml
npx wrangler deploy                           # получите адрес вида https://stebel-orders.<имя>.workers.dev
```

В `wrangler.toml` добавьте:

```toml
[[kv_namespaces]]
binding = "SESSIONS"
id = "<id из команды выше>"
```

Секреты задаются командой `npx wrangler secret put ИМЯ`, а не в коде.

## 2. Заявки менеджеру в Telegram и во внешнюю CRM

| Секрет | Где взять |
| --- | --- |
| `TG_BOT_TOKEN` | @BotFather → /newbot |
| `TG_MANAGER_CHAT_ID` | Напишите боту, откройте `https://api.telegram.org/bot<токен>/getUpdates`, возьмите `chat.id` |
| `CRM_WEBHOOK_URL` | Входящий вебхук вашей CRM (в amoCRM и Bitrix24 — через раздел интеграций/вебхуков) |

Затем в `js/config.js` впишите `webhookUrl: "https://…workers.dev/order"`.

## 3. Авито

Главный канал для многих продавцов. Нужен аккаунт Авито с доступом к API (тариф с API для бизнеса) и приложение в разделе «Для профессионалов → API».

| Секрет | Где взять |
| --- | --- |
| `AVITO_CLIENT_ID`, `AVITO_CLIENT_SECRET` | Личный кабинет Авито → API → ключи приложения |

Сервер сам получает токен доступа (он живёт сутки) и держит его в KV.
Вебхук сообщений подключается методом Мессенджер API `POST /messenger/v3/webhook` с адресом `https://…workers.dev/avito`.

Что важно знать:
- В чатах Авито бот не может показывать кнопки, поэтому варианты идут списком «1 — …», покупатель отвечает цифрой.
- Разговор начинается с объявления: в `js/profile.js` → `avito.items` задайте, какому товару соответствует номер объявления — тогда бот сразу знает, о чём речь.
- Адаптер написан по документации Авито Мессенджер API (вебхук v3, отправка `POST /messenger/v1/accounts/{id}/chats/{chat}/messages`). Точный лимит длины сообщения я в документации не нашёл, поэтому бот держит ответы до 1000 знаков. Перед запуском сверьте с актуальной документацией.

## 4. Бот в Telegram

Тот же `TG_BOT_TOKEN`. Регистрация вебхука:

```
https://api.telegram.org/bot<токен>/setWebhook?url=https://…workers.dev/telegram&secret_token=<придумайте>
```

Секрет сохраните как `TG_SECRET`.

## 5. ВКонтакте

Сообщество → Управление → Работа с API:
- **Ключи доступа** → создать ключ с правом «сообщения сообщества» → секрет `VK_TOKEN`.
- **Callback API** → адрес `https://…workers.dev/vk`, версия 5.199; строку подтверждения сохраните как `VK_CONFIRMATION`, секретный ключ — как `VK_SECRET`. В типах событий включите «Входящее сообщение».
- **Сообщения** → включить; **Настройки для бота** → включить возможности ботов.

## 6. MAX

Создайте бота на платформе MAX для бизнеса, получите токен → `MAX_TOKEN`.
Подпишите бота на вебхук `https://…workers.dev/max` (метод подписки на обновления в Bot API MAX).
Адаптер написан по документации MAX Bot API (`POST /messages`, inline-клавиатура, `message_callback`).
Перед запуском сверьте адрес API и способ передачи токена с актуальной документацией — платформа молодая и меняется.

## 7. Алиса (Яндекс Диалоги)

dialogs.yandex.ru → Создать диалог → Навык:
- Backend: Webhook URL `https://…workers.dev/alice`.
- Хранилище состояния: включить «Использовать хранилище данных в навыке» (нужно для `session_state`).
- Пройти модерацию. До публикации навык можно проверить во вкладке «Тестирование».

## 8. Яндекс.Метрика

Создайте счётчик на metrika.yandex.ru, номер впишите в `js/config.js` → `metrikaId`.
Цели создайте типа «JavaScript-событие» с идентификаторами:
`cart_add`, `cart_open`, `checkout_error`, `order_sent`, `chat_open`, `chat_order`, `callback_request`, `payment_success`.

## Что ещё есть у Яндекса

- **Яндекс Бизнес / чаты на Картах.** Клиенты могут писать организации прямо с карточки на Картах.
  Открытого API для подключения своего бота туда я не нашёл. Это нужно проверить в кабинете Яндекс Бизнеса перед планированием.
- **Яндекс Директ** — реклама. Цели Метрики выше можно использовать для оптимизации кампаний.

## Ограничения, которые проверяют тесты

| Канал | Текст | Кнопки |
| --- | --- | --- |
| Авито | до 1000 символов (наш запас), одно сообщение на ответ | нет — варианты цифрами, до 9 |
| Telegram | до 4096 символов | callback_data до 64 байт |
| ВКонтакте | до 4096 символов | inline: до 6 рядов и 10 кнопок, подпись до 40 символов, payload до 255 |
| MAX | до 4000 символов | подпись до 64 символов |
| Алиса | до 1024 символов, голос до 1024 | заголовок кнопки до 64 символов; в голосе нет ссылок и значков |

Значения взяты из документации платформ на момент написания. Если платформа их поменяет, исправьте `LIMITS` в `js/channels.js`.
